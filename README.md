## helpers directory
I try to use some modules for better code.
- `constants.py` - all constants from functions. I sure, that magical numbers have to be  replaced by constants with clear name.
- `fastq.py` - some subfunctions for `filter_fastq()`

# What inside
### `filter_fastq()`
So, in this function for filter reads in FASTQ file.You can set filtration by:
- GC fraction
- quality threshold
- sequence length

### `convert_multiline_fasta_to_oneline()`
Concatinate multiple lines in one. Simple, dude.

### `parse_blast_output()`
Parsing proteins description from blast output into sorted list.
